# Medical Cost Prediction

Predicts individual medical insurance charges from age, BMI, smoking status,
number of children and region, using linear regression.

## Dataset
`medical.csv` (1,338 records)

## Steps
1. Exploratory data analysis
2. Linear regression on smokers and non-smokers
3. Model evaluation with RMSE

## Tech
Python, pandas, NumPy, Plotly, scikit-learn
